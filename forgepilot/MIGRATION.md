# ForgePilot 工业管理与迁移契约

本版本提供工业本体、接入配置与通用管理能力，使用独立工业数据库与工业目录。

| 范围 | 当前状态 |
|---|---|
| 工业对象、属性、关系、公理与发布 | 保留，使用工业目录与来源契约 |
| 关系图、概念邻域、闭包与路径 | 保留，区分工作模型预览与发布缓存 |
| 数据源、JDBC扫描、字段映射 | 保留，生产连接必须有真实字典与受控权限 |
| 工业连接器工厂 | 保留，同版本维护配置与字段，校验不启动同步 |
| 术语、指标、制度文档与知识检索 | 保留，默认无生产源与SQL探针 |

## 不可变工业迁移

V1是已发布工业元数据结构，V2是45类工业对象、属性、关系、规则、指标、术语及本机演示账号，V3是连接器配置与审计。V1/V2的字节及校验不改写；生成器只读取固定的 `baseline/platform.sql`、`baseline/auth-seed.sql` 和工业目录，不再读取原应用迁移。

历史工业V1可能保留不再使用的平台空表定义。这些表没有业务处理器、演示源连接、数据播种或执行入口；本次不删除现有工业数据，也不连接或清理其他业务数据库。

## 事实与执行边界

MySQL保存模型与配置，ForgePilot保存案例与业务事实。`fp_model_contract`保留单位、类型、来源、基数和动作副作用；模型目前为DRAFT。18类演示适配定义与27类待源对象分别标记，不创建虚构的物料、订单、发票或付款实例。

连接器工厂中的HTTP/JSON集合不会写入运行时MySQL物理映射。只有取得真实源字典、只读凭据与组织授权后，才在原JDBC工作台维护实际表列。未知值保留unknown，承诺或链上回执不能代替实物与质量资格。

Java模型审核发布、业务运行器版本绑定、生产源采集和模型摘要上链仍为后续范围。
